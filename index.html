Left Panel: Algorithm Input Plain English

1. Take an array of positive integers.

2. Find two numbers that sum up to target.

3. Use an unordered hash map for single-pass.

4. If match exists, return indices.

5. If no match found, return empty array.

Target: C++ / Python / Java / JS ● Logic Parsed
Top Right: Synthesized C++ Code Google Gemini 1.5 AI 
vector twoSum(vector& nums, int target) {
    unordered_map mp;
    for (int i = 0; i < nums.size(); i++) {
        int diff = target - nums[i];
        if (mp.count(diff)) return {mp[diff], i};
        mp[nums[i]] = i;
    }
    return {};
}
Bottom Right: Live I/O Sandbox Console Status: 200 OK (8ms)
Input: [2, 7, 11, 15], target = 9
Output: [0, 1] (Indices Verified & Saved to MongoDB Atlas)
